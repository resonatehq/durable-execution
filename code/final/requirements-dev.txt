# The kernel, the engine, the codec, the simulators and the SDK depend on
# nothing. That is a property worth keeping, so it is stated here as much as
# anywhere: the first group is what it takes to *check* the code, and the
# second is what it takes to *deploy* it. Nothing in the first group is
# imported by anything that runs in production, and nothing in the second is
# imported by anything the kernel is made of.

# -- to run the tests -------------------------------------------------------
pytest
hypothesis
jsonschema

# The module specs in spec/ are claims in the type
# system, and no test can check a type-system claim. `test_types.py` runs
# mypy over them and skips itself when mypy is absent.
mypy
